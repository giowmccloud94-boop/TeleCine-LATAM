# TeleCine-LATAM

Blog estático sobre la historia de la televisión, el cine, la animación y otros medios audiovisuales de Latinoamérica.

## Objetivo

Documentar la evolución de los medios audiovisuales en la región con artículos de enfoque histórico y documental, considerando las diferencias entre países y utilizando fuentes verificables.

## Tecnologías

- HTML5
- CSS3
- JavaScript nativo

El proyecto no requiere frameworks, dependencias ni un servidor backend.

## Estructura

```text
.
├── articulos/       # Artículos del blog
├── css/             # Hoja de estilos
├── img/             # Imágenes y créditos de Wikimedia Commons
├── js/              # JavaScript del sitio
├── paginas/         # Páginas de categorías
└── index.html       # Página principal
```

## Abrir localmente

Abre `index.html` en un navegador web. También puedes abrir la carpeta del proyecto en Visual Studio Code y usar una extensión de servidor estático si deseas recarga automática.

## Publicaciones futuras

Los artículos nuevos se agregarán como archivos HTML dentro de `articulos/` y se enlazarán desde las páginas correspondientes. Las fechas, afirmaciones y referencias deben revisarse antes de publicar cada artículo.

## GitHub Pages

El sitio está preparado para publicarse como sitio estático, con `index.html` en la raíz y rutas relativas a CSS, JavaScript e imágenes. Para publicarlo, habilita GitHub Pages desde la configuración del repositorio y selecciona la rama `main` y la carpeta raíz (`/`). No se requiere dominio personalizado.
